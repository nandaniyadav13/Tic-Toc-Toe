# Tic-Toc-Toe 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS and JavaScript.

## Features

- Player vs Player mode
- Player vs Computer mode
- Easy, Medium and Hard difficulty levels
- Score tracking for X and O
- Draw counter
- Winner popup
- Draw popup
- Winning cells highlight
- Restart Game option
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Choose Player vs Player or Player vs Computer.
2. Select a difficulty level when playing against the computer.
3. Player X starts the game.
4. Get three same symbols in a row, column or diagonal to win.
5. If all cells are filled without a winner, the game is a draw.
